# Mi portfolio · Rafael Osuna Ventura

Soy técnico superior en Administración de Sistemas Informáticos en Red e Ingeniero Informático. He creado este portfolio para reunir mis proyectos, compartir mi currículum y mostrar lo que he ido aprendiendo en desarrollo, sistemas, redes y ciberseguridad.

Entre mis proyectos destacados están una aplicación de Telegram para gestionar partes de trabajo agrícola, un invernadero automatizado con Arduino, un robot de reparto con LEGO EV3 y un simulador del sistema solar en C++ y OpenGL. En el catálogo también muestro trabajos de domótica con Raspberry Pi y Arduino, un proyecto de cableado estructurado con su plano original y prácticas de ASIR y de la universidad.

He desarrollado la web con React, TypeScript y Vite. Uso GSAP para las animaciones y GitHub Pages para el despliegue.

## Ejecutarlo en local

Con Node.js 24 instalado, ejecuta estos comandos desde la carpeta del proyecto.

```sh
npm ci
npm run dev
```

`npm run build` comprueba los tipos y genera el sitio en `dist/`. Los textos y las fichas del portfolio están en `src/data/`.
